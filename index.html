JavaScript

文A 149 languages ▾

From MBD, the free knowledge platform

JavaScript is a programming language and core technology of the Web, alongside HTML and CSS. 99% of websites use JavaScript on the client side for webpage behavior.

It enables interactive web pages and is an essential part of web applications.

Originally developed by Brendan Eich in 10 days at Netscape, JavaScript has become one of the world's most widely used programming languages.

JavaScript is prototype-based, multi-paradigm, single-threaded, dynamic, and supports functional, imperative, and object-oriented styles.

JavaScript engines power everything from websites to servers, mobile apps, games, and even AI-driven platforms.
